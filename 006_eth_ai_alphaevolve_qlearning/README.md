## 策略重训与熔断规范 (Walk-Away Rules)

为防止遗传算法过度拟合特定历史波段而在未来市场突变时穿仓，严格执行以下量化重训机制：

1. **定量熔断停机**：
   - 连续 3 笔交易触碰硬止损；
   - 最近 20 笔实盘胜率跌破 45%（标称 75%+）；
   - 净值动态回撤超过 12%（标称 9.83%）。
2. **滚动重训 (Rolling Walk-Forward)**：
   - 每隔 14~30 天，以过去 180 天 15m K线为输入，重新在 Kaggle/本地 GPU 运行 20,000 代演化，导出最新 $ 参数。
