# 001_smc_matrix 多资产 SMC 动量回踩与狄利克雷证据门控策略矩阵

## 1. 策略理念详细介绍 (Strategy Philosophy)

### 1.1 核心思想与数学建模
本系统是基于 **Nautilus Trader 2.0 (Rust/Python 混合事件驱动架构)** 构建的多资产、多标的量化交易系统。其理念核心在于捕捉由宏观与机构资金流引发的**高信噪比动量回踩结构**，并结合贝叶斯主观逻辑（Subjective Logic）与 **Credal Transformer (arXiv:2510.12137)** 实现严格的认知真空度与多空冲突度过滤，彻底消除深度学习与技术指标模型中常见的“人工确定性”（Artificial Certainty）幻觉。

1. **趋势主干判定 (Trend Identification)**：
   - 双重指数移动平均线系统（EMA 20 与 EMA 50），严格确保在多头顺势（$Close > EMA_{20} > EMA_{50}$）或空头顺势（$Close < EMA_{20} < EMA_{50}$）时触发动量追踪。
2. **K 线微观压强与异动量能 (CLV & Volume Absorption)**：
   - **收盘位置值 (CLV, Close Location Value)**：
     $$CLV = \frac{(Close - Low) - (High - Close)}{High - Low}$$
     CLV 处于 $(-1.0, 1.0)$ 区间，量化收盘价格在单根 K 线振幅中的绝对强弱，多头回踩需 $CLV > 0.4$，空头需 $CLV < -0.4$。
   - **量能突变 (Volume Spike / VolProxy)**：基于成交量 20 周期均线，要求单根 K 线成交量放大超过 $1.25\times$，确认机构资金吸收行为。针对无单源成交量的宏观指数（如 CMC20），采用波动率扩张代理机制（$VolProxy = (High - Low) \times 1000$）还原真实流动性。
3. **波动率有效区间 (Volatility Regime)**：
   - 基于 $ATR_{14} / ATR_{50}$ 波动率比率，过滤过窄的死寂横盘（$<0.55$）与不可控的流动性抽干/插针行情（$>1.80$）。
4. **狄利克雷主观逻辑门控 (Dirichlet Evidential Gate - Credal Transformer 理论)**：
   - 传统指标最大的缺陷在于震荡行情中频繁虚警。本策略引入主观逻辑（Subjective Logic），将指标评分映射为多头证据 $\alpha_{bull}$、空头证据 $\alpha_{bear}$ 及中立证据 $\alpha_{neutral}$：
     $$\alpha_{bull} = \frac{Score_{long}}{10} + 1, \quad \alpha_{bear} = \frac{Score_{short}}{10} + 1, \quad S = \alpha_{bull} + \alpha_{bear} + \alpha_{neutral}$$
   - 计算认知真空度（Uncertainty, $u = \frac{3}{S}$）与多空冲突度（Conflict, $C = \frac{2 \min(b_{bull}, b_{bear})}{b_{bull} + b_{bear}}$）。
   - 仅在 $u \le 0.35$ 且 $C < 0.40$ 时放行开仓，严防多空胶着时的假突破。
5. **动态剩余保证金并发切分 (Dynamic Margin Concurrency)**：
   - 同一账户内运行多周期或多币种时，严格依据实时账户剩余可用保证金（Free Margin）计算分配池。
   - 多个信号同时间闭合触发时，按照信号评分权重切分可用保证金，实现风险预算与资金利用率的最优自适应平衡。
   - 所有平仓委托强制携带 `reduce_only=True`，杜绝任何超额反向裸开仓风险。

## 2. 优化方案与演进历程 (Optimization & Evolution)

针对 2026-09-30 发布的基线版本在实测中发现的问题，实施了系统的调优方案：

### 2.1 发现的致命问题
- **15m 高频过度磨损**：在 15 分钟级别下，24~34 个月产生数千笔交易，双边 Maker（0.02%）与 Taker（0.05%）手续费高达数万至数十万 USDT，策略被高额交易摩擦吞噬。
- **原始熔断死锁 (Circuit Breaker Deadlock)**：老策略在连亏 3 笔后直接 `Trading halted.`，由于缺少冷却解封计数器，导致各品种在震荡市被永久锁定，失去交易活性。

### 2.2 核心优化落地
1. **升维 K 线周期（15m -> 1h / 2h / 4h）**：将入场周期拉升至 1 小时至 4 小时大级别，过滤微观高频噪波，**将总手续费损耗降低 83% 以上**。
2. **放大盈亏比空间（TP 从 2.0R 提升至 2.5R / 3.0R）**：在趋势跟踪 30%~38% 胜率下，更大的盈利空间赋予策略极高的非对称正向数学期望（单笔盈亏比达到 2.3 ~ 3.0 倍）。
3. **同账户多时框/多资产并发 (Multi-Stream Portfolio)**：打破单周期限制，支持同一账户并发接收 1h+2h+4h 或跨币种信号，按剩余保证金弹性切分。
4. **引入宏观加密指数标的 (CMC20 Index)**：利用 CMC20 前 20 大币种加权指数抹平单一币种的插针控盘，捕捉全市场宏观贝塔趋势。

## 4. 目录指引与交付物规范
每个策略版本子目录均严格配备 3 大生产级交付物：
1. `smc_live_trader_*.py`：可直接加载于 NautilusTrader 实盘节点或 Docker 回测节点的生产级源码。
2. `trade_log_*.csv`：逐笔级交易明细日志（时间戳、开平仓价、张数、杠杆名义本金、双边手续费、单笔净盈亏、实时账户净值与出场归因）。
3. `report_*.md`：包含核心业绩指标、10,000 次蒙特卡洛极端压力推演、±0.15% 噪声+3倍滑点扰动敏感性及 IS/OOS 样本内外 WFE 泛化度检验报告。
