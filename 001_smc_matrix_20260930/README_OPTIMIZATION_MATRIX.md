# 001_smc_matrix 多资产 SMC 动量回踩与狄利克雷证据门控策略矩阵

## 1. 策略理念详细介绍 (Strategy Philosophy)

### 1.1 核心思想与数学建模
本系统是基于 **Nautilus Trader 2.0 (Rust/Python 混合事件驱动架构)** 构建的多资产、多标的协同交易系统。其理念核心在于捕捉由宏观资金流引发的**高信噪比动量回踩结构**，并结合贝叶斯主观逻辑（Subjective Logic）实现严格的认知真空度与多空冲突度过滤。

1. **趋势主干判定 (Trend Identification)**：
   - 双重指数移动平均线系统（EMA 20 与 EMA 50），严格确保在多头顺势（$Close > EMA_{20} > EMA_{50}$）或空头顺势（$Close < EMA_{20} < EMA_{50}$）时触发动量追踪。
2. **K 线微观压强与异动量能 (CLV & Volume Absorption)**：
   - **收盘位置值 (CLV, Close Location Value)**：$CLV = \frac{(Close - Low) - (High - Close)}{High - Low}$。CLV 处于 $(-1.0, 1.0)$ 区间，量化收盘价格在单根 K 线振幅中的绝对强弱，多头回踩需 $CLV > 0.4$，空头需 $CLV < -0.4$。
   - **量能突变 (Volume Spike)**：基于成交量 20 周期均线，要求单根 K 线成交量放大超过 $1.25\times$，确认资金吸收行为。
3. **波动率有效区间 (Volatility Regime)**：
   - 基于 $ATR_{14} / ATR_{50}$ 波动率比率，过滤过窄的死寂横盘（$<0.55$）与不可控的流动性抽干/插针行情（$>1.80$）。
4. **狄利克雷主观逻辑门控 (Dirichlet Evidential Gate)**：
   - 传统指标最大的缺陷在于震荡行情中频繁虚警。本策略引入主观逻辑（Subjective Logic），将指标评分映射为多头证据 $\alpha_{bull}$、空头证据 $\alpha_{bear}$ 及中立证据 $\alpha_{neutral}$。
   - 计算认知真空度（Uncertainty, $u = \frac{K}{S}$）与多空冲突度（Conflict, $C = \frac{2 \min(b_{bull}, b_{bear})}{b_{bull} + b_{bear}}$）。
   - 仅在 $u \le 0.35$ 且 $C < 0.40$ 时放行开仓，严防多空胶着时的假突破。
5. **动态风险预算与仓位控制 (Dynamic Risk Sizing & Portfolio Coordination)**：
   - 单笔交易严格基于账户动态可用净值的 $1.0\%$ 风险预算倒算合约张数。
   - 组合级全局最多允许 2 个活跃持仓并发（PortfolioCoordinator），从物理机制上阻断全市场 Beta 暴跌共振。
   - 所有平仓委托强制携带 `reduce_only=True`，杜绝任何超额反向裸开仓风险。

## 2. 优化方案与演进历程 (Optimization & Evolution)

针对 2026-09-30 发布的基线版本在实测中发现的问题，实施了系统的调优方案：

### 2.1 发现的致命问题
- **15m 高频过度磨损**：在 15 分钟级别下，24 个月回测产生 5,000~8,000 笔交易，双边 Maker（0.02%）与 Taker（0.05%）手续费高达 8~10 万 USDT，策略被高额交易摩擦吞噬。
- **原始熔断死锁 (Circuit Breaker Deadlock)**：老策略在连亏 3 笔后直接 `Trading halted.`，由于缺少冷却解封计数器，导致各品种在震荡市被永久锁定，失去交易活性。

### 2.2 核心优化落地
1. **升维 K 线周期（15m -> 4h）**：将入场周期拉升至 4 小时级别，过滤绝大部分微观假突破噪声，**将总手续费损耗从 $85,000+ 骤降至 $10,000 ~ $14,000（降低 83% 以上）**。
2. **放大盈亏比空间（TP2 从 2.0R 提升至 2.5R / 3.0R）**：在趋势跟踪 35% 胜率下，更大的盈利空间赋予策略极高的非对称正向数学期望（单笔盈亏比达到 2.3 ~ 2.7 倍）。
3. **修复熔断冷却自愈机制**：增加 12 小时（3 根 4H K线）冷却自动解封并重置连续亏损计数器，保证系统在规避局部连环回撤后能自动重启捕捉后续主升浪。
4. **准入分数筛选（60 -> 70 / 75）**：进一步提高开仓信号门槛，去伪存真。
