## 一、 策略核心哲学与黑盒真相解密（Debunking & Truth）

1. **真实物理机制（Debunking）**：
   - 实盘阶段大模型与深度神经网络参与度为 **0%**；交易决策由离线演化导出的**确定性递推闭式方程**完成，单次计算耗时 $< 0.1 \text{ ms}$，彻底斩断在线大模型幻觉与 API 超时丢包风险；
2. **Q-Learning 状态价值涌现的本质**：
   - 算法在非对称回撤惩罚（$\text{Reward} = \text{Calmar} - 15.0 \times \text{MDD}^2$）的驱动下，自发收敛出**带折现因子的时序差分（TD）滑动累积算子（一阶 IIR 低通滤波器）**：
