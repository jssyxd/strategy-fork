# 002 多资产线内即时成交重算矩阵策略 (002_intrabar_recalc_matrix)

## ⚡ 核心定位与投研宣言 (Strategy Thesis)

> **“没有线内即时成交重算（Instant Recalculation on Order Filled），本策略从数学与物理上完全不成立！”**

在量化多资产中长周期（如 3H / 4H）或者中高频周期（15m / 1h）策略设计中，传统向量化或简易事件驱动回测普遍存在致命缺陷——**“K线收盘假想（Bar-Close Assumption）”**：
1. 策略在第 $t$ 根 3H K线开端或者形态突破时，向盘口挂出限价单（Limit Order）；
2. 订单在第 15 分钟于柱线内部被触碰击穿；
3. **传统错误回测引擎**：策略“失明”等待剩余的 2 小时 45 分钟直到 3H 柱收盘，才获取成交结果、计算止损和止盈。在这长达数小时的风控盲区中，价格早已击穿底线或坐过山车，造成巨大的**信息延迟黑洞（Information Lag）与裸露风控敞口**。

本项目严格遵循 TradingView `calc_on_order_fills = true` 与 **Nautilus Trader 事件驱动引擎 `on_order_filled(event)`** 的原子级底层机制，彻底解决微观执行与盘口摩擦问题。

## 一、 微观问题与摩擦问题的深度剖析 (Microstructure & Friction)

### 1.1 微观摩擦的物理死穴：为什么简易回测全是“假神话”？
许多策略在粗糙的历史回测中展现出完美的胜率与资金曲线，但一旦上线实盘或者接入 Nautilus Trader 原生逐笔撮合，净值便瞬间崩塌。其根本原因在于未能正视以下四大微观物理摩擦：
1. **单笔毛利与摩擦成本的不对称（Spread & Commission Drag）**：
   - 资产的每次真实交易均伴随确定性的物理摩擦损耗：交易所手续费（Taker 3~5 bps，Maker 1~2 bps）+ 盘口半价差（Half-Spread 1~3 bps）+ 冲击滑点（Slippage 2~5 bps）；
   - 若策略缺乏**线内被动限价单价格改善（Price Improvement）**，全用 Taker 市价入场，单边 6~8 bps 的摩擦成本将在数百次交易后彻底吞噬全部 Alpha（我们在 010 策略真实回测中已证实：15m 换手率下累计产生超 $6,100 USDT 摩擦损耗导致亏损 -87%）。
2. **同柱双向突破的悲观碰撞陷阱（Pessimistic Collision Bias）**：
   - 当一根 3H K线或剧烈波动的 15m K线内部，最高价触碰止盈线、最低价同时跌破止损线时，简易回测软件往往默认“先止盈盈利”；
   - **投研宪法严苛铁律**：本引擎强制引入**悲观碰撞判定（Pessimistic Stop-Loss Priority）**。只要微观无法证明先触碰止盈，一律强制按止损甚至滑点跌破结算，绝无任何迎合性虚增。

### 1.2 为什么说“没有线内即时成交重算，策略绝对不成立”？
本策略的胜率核心依赖于**动态波动率包络线（ATR Risk-Parity Bracket）**：
- 我们的止损与止盈点位不是固定的静态价格，而是严格绑定在**“真实成交价格（Actual Executed Fill Price）”**之上：
  $$	ext{Target TP} = P_{	ext{executed}} + 2.4 	imes 	ext{ATR}_{14}$$
  $$	ext{Stop Loss} = P_{	ext{executed}} - 1.2 	imes 	ext{ATR}_{14}$$
- 若没有 `on_order_filled` 机制，回测只能用“假想的挂单价”或“3H 结束后的收盘价”做基准。但在实际撮合中：
  - 市场经常出现向上/向下跳空击穿挂单价；
  - 实际成交价 $P_{	ext{executed}}$ 与期望价存在数个基点的微观滑点；
  - **只有在订单被 Filled 的微秒瞬间，策略立即打断等待、捕获实际成交凭据（Fill Execution Receipt），并在同一个微观时间片内瞬时挂出伴随的 OCO（One-Cancels-the-Other）保护性止损止盈单，策略的数学期望（Positive EV）与盈亏比（RRR 2:1）才具有物理现实性！**

## 四、 后续待增进与工程迭代路线 (Future Enhancements)

尽管本策略在 1m 微观切片仿真下展现出卓越的风险收益特征，但在迈向真实上实盘（Live Trading）前，仍有以下核心模块待进一步增进：

1. **L2/L3 订单簿深度与挂单队列排队仿真 (Queue Position Modeling)**：
   - 目前微观切片基于 1 分钟 OHLCV 判断触碰；在真实极端行情中，挂单位于买一/卖一队列末尾，可能存在“触碰但未完全成交（Partial Fill / Missed Fill）”现象；
   - **待增进方案**：接入币安 / OKX 历史 OrderBook 深度数据，使用 Nautilus Trader 的 `OrderBookDelta` 建立真实排队与主动撤单惩罚模型。
2. **跨资产风险平价与保证金动态抢占仲裁 (Cross-Asset Margin Coordinator)**：
   - 当黄金、白银、BTC 在同根 3H 柱体内同时触发线内成交时，多资产并发可能瞬间耗尽可用保证金；
   - **待增进方案**：引入类似 001 SMC 策略中的 `PortfolioCoordinator`，基于 Dirichlet 证据不确定性评分动态打折分配各资产开仓名义价值。
3. **动态追踪止损 (Trailing Stop) 与微观盘口毒性过滤 (VPIN Filter)**：
   - 目前止损固定为入场点位下方的 1.2 * ATR；
   - **待增进方案**：当行情已实现 1.5 * ATR 浮盈时，自动将止损线移动至入场均价（Break-even Stop），并引入成交量同步逆向选择（VPIN）指标识别机构毒性订单流。
