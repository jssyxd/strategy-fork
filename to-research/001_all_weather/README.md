## 一、目标基准定义（研发成功的最终约束）

> **该基准被声明为策略研发成功的定义与最终约束**：只有在同口径数据上、计入真实手续费与滑点后复现下列指标（容差内），并通过样本外 / 滚动验证，方可判定策略研发成功。

| 指标 | 目标值 | 验收容差（最终约束） |
| :--- | :---: | :--- |
| 年化收益率 (CAGR) | **24.1%** | 绝对偏差 ≤ **±1.5 个百分点** |

## 二、策略核心机制与数学原理

1. **宏观周期判定（四象限）**：以「增长 / 通胀」两维划分四象限；增长分由 PMI 动量、M1-M2 剪刀差、社融脉冲、10Y 国债收益率变动合成；通胀分由 CPI-PPI 剪刀差与 PPI 环比动量合成。
2. **ERC 等风险贡献配置**：以边际风险贡献 (MRC) 迭代使各资产风险贡献方差最小化，配 Ledoit-Wolf 协方差收缩抑制样本噪声。
3. **动态风险预算倾斜**：宏观打分越过阈值（如 0.8）时对顺周期资产做风险预算倾斜，并以乘法权重更新 (MWU) 惩罚落后资产。
4. **DOTM 尾部对冲**：以年化约 1.5% 预算滚动买入 5%~10% 虚值看跌期权，在波动率由低转高时提供非线性凸性收益。
