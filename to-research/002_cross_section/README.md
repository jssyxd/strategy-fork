## 二、策略核心机制与数学原理

1. **端到端 Transformer 截面建模**：以个股时序特征 + 截面注意力直接输出收益预测，替代“因子加权”的线性范式。
2. **Low-rank Decay (LoRD)**：对注意力权重矩阵施加核范数低秩衰减正则（Newton-Schulz 迭代），防止注意力秩坍塌与过拟合。
3. **金融意义 Aux Loss**：对具备金融含义的目标（如分组单调性、截面 IC）加辅助损失约束。
4. **Alpha101 / Meme 因子融合**：融合量价类公式因子库提升特征表达。
