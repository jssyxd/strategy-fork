## 二、策略核心机制与数学原理

1. **端到端截面建模**：以个股时序特征 + 截面注意力直接输出收益预测，替代「因子加权」的线性范式。
2. **低秩衰减 (Low-rank Decay)**：对注意力权重矩阵施加核范数低秩正则（Newton-Schulz 迭代），防止注意力秩坍塌与过拟合。
3. **金融意义辅助损失**：对分组单调性、截面 IC 等具备金融含义的目标加辅助约束。
4. **公式因子融合**：融合量价类公式因子库提升特征表达。
