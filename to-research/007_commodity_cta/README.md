## 二、策略核心机制与数学原理

1. **期限结构展期收益率**：`Roll Yield = ln(P_near/P_far) × (365/Δt)`；Backwardation 强多、Contango 规避。
2. **时序动量 (TSMOM)**：多周期均线与波动率标准化动量。
3. **宏观/行为因子**：库存周期、进出口差额、行为经济学因子。
4. **跨品种风险配置**：HRP 层次风险平价聚类 + 保证金/整数手约束。
