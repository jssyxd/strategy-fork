## 二、策略核心机制与数学原理

1. **期限结构展期收益率**：`Roll Yield = ln(P_near / P_far) × (365 / Δt)`；Backwardation 强多、Contango 规避。
2. **时序动量 (TSMOM)**：多周期均线与波动率标准化动量。
3. **宏观 / 行为因子**：库存周期、进出口差额、行为经济学因子。
4. **跨品种风险配置**：层次风险平价 (HRP) 聚类 + 保证金 / 整数手约束。

### 4.1 实测诊断：为什么单纯无期限结构的海外期货无法复现国内商品 CTA 表现？

我们实测拉取了 2020-01 至 2026-09 期间连续 **1,696 根全球 6 大核心商品期货（WTI原油、黄金、白银、铜、玉米、大豆）的真实日线数据**，在执行纯趋势动量与波动率目标调仓测试后，实测表现如下：

```
----------------------------------------------------------------------
全球 6 大商品期货 TSMOM 时序动量实测 (2020-2026, 1,696 交易日)
----------------------------------------------------------------------
年化复合收益率 (CAGR):   4.76% ~ 15.02% (验收目标: 22.4%)
年化夏普比率 (Sharpe):   0.61  ~ 0.66   (验收目标: 1.65)
卡尔玛比率 (Calmar):     0.28  ~ 0.31   (验收目标: 2.1)
最大历史回撤 (MaxDD):    15.31% ~ 53.08%
----------------------------------------------------------------------
```

> **🚨 关键结论与数据门槛约束**：  
> 1. 单纯的商品时序动量在缺乏展期收益率（Carry / Roll Yield）保护时，易在 2020 年原油极端负油价与 2022 年加息周期中遭遇剧烈反抽与假突破；
> 2. 国内顶尖商品 CTA（CAGR 22.4%, Sharpe 1.65, Calmar 2.1）的 Alpha **深度依赖于国内期货（螺纹、焦炭、纯碱、铁矿等）主力与次主力合约的高贴水多头/高升水空头展期收益率截面**；
> 3. 在接入包含国内商品期货各合约每日收盘、持仓量、展期收益率与仓单库存的商业级期货数据库（如聚宽 / 优矿 / Tushare Pro / 万得）之前，**根据《反造假宪法》，严禁通过人工合成假数据声称达标，必须如实保持「待真实国内商品期货期限结构数据接入」状态！**
