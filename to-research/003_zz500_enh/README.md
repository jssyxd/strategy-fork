## 二、策略核心机制与数学原理

1. **AlphaGPT 自动因子挖掘**：以符号遗传规划/强化学习自动搜索高质量公式化 Alpha 因子。
2. **MWU 因子 Stacking**：以乘法权重更新（严格无悔界）对多因子在线加权，自适应淘汰失效因子。
3. **LightGBM 底座**：处理因子共线性并输出个股 alpha 打分。
4. **指数增强约束**：行业/风格中性化 + 主动权重截断 + 跟踪误差控制。
