## 二、策略核心机制与数学原理

1. **保留价格**：`r(s,q,t) = s − q·γ·σ²·(T−t)`，库存 `q` 决定内部公允价偏移方向。
2. **最优非对称价差**：`δ_half = (1/γ)·ln(1+γ/κ)·(1+3σ)`，叠加库存偏置使买卖挂单非对称。
3. **趋势非对称过滤**：单边行情下仅允许同向做市，切断逆势马丁加仓。
4. **防御状态机**：回撤 / 库存 / 保证金触限即进入防守，只减不加。
