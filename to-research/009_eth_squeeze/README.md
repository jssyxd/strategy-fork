## 二、策略核心机制与数学原理

1. **SVI 波动率曲面建模**：拟合隐含波动率曲面，识别 IV-RV 短期严重偏离。
2. **RV 预测**：以高频已实现波动率预测短期波动率走向。
3. **期权多腿状态机**：IV 低估 → 买入跨式 (Straddle) 做多波动率；IV 高估 → 卖出铁鹰 (IronCondor) 收取 Theta；爆发预警 → 立即平仓保护。
4. **可解释定价**：物理信息神经网络 (PINN) 约束衍生品偏微分方程 + 稀疏自编码器解耦希腊字母。
