## 二、策略核心机制与数学原理

1. **深度学习动量跟踪**：多周期均线动量加速度 + 波动率状态机识别主升浪 / 震荡 / 崩溃三态。
2. **动态波动率滤网**：高波动恐慌区压缩敞口，低波动顺势期放大敞口。
3. **Delta-Gamma 期权增强**：以 QQQ 期权链做下跌对冲、上涨时降低对冲成本，增强指数复制收益。
4. **基准相对强弱**：与 QQQ / S&P500 动态比对控制跟踪误差。
