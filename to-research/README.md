# 待研究与回测策略池 (To-Research Strategy Pool)

本目录存放**尚待研究、复刻与回测验证**的量化策略。所有策略均为依据公开量化资料、公开模型与工程素材独立整理与实现的研究原型。

> **核心约束（重要）**：每个策略目录的 `README.md` 第一节写明该策略的**目标基准定义**（CAGR / Sharpe / 第三指标 / 简介 / 设计 / 参数 / 容量）。
> **该目标基准即被声明为「策略研发成功」的定义与最终约束**——只有在同口径数据上、计入真实手续费与滑点后复现目标指标（容差内）并通过样本外 / 滚动验证，方可判定研发成功。

## 代码完善度评估标准

**代码完善度 = 该策略直接可投入回测的程度，100% 表示「数据齐备、逻辑完整、可直接挂数据跑回测」。**

| 维度 | 权重 | 说明 |
| :--- | :---: | :--- |
| 信号 / 策略逻辑 | 40% | 核心模型与交易逻辑的完整度 |
| 数据接口 | 20% | 行情 / 基本面数据接入是否就绪 |
| 回测 / 执行框架 | 20% | 回测引擎与订单执行链路 |
| 风控与实盘工程 | 20% | 风控、状态机、部署与运维 |

## 理论论文（每个策略目录内）

每个策略目录都附带：

- **`THEORY_PAPERS.md`** — 该策略涉及的理论与技术脉络说明，逐篇给出「为什么相关」。
- **`papers/`** — 相关论文的 **arXiv 全文 PDF**；SSRN / DOI 论文以官方链接形式列入文档。

> 说明：arXiv 论文为开放获取，已经过 arXiv API 检索并核对标题后下载；SSRN 论文编号与链接经 **Crossref**（DOI `10.2139/ssrn.*`）核对，
> 但 SSRN 站点对自动化访问启用了 Cloudflare 校验，**正文 PDF 无法随目录提供**，仅提供官方链接与相关性说明。

## Kaggle 关联资源（每个策略目录内）

除理论论文外，每个策略目录还附 **`KAGGLE_RESOURCES.md`**：在 Kaggle 上逐策略检索得到的可复用资源索引——

- **数据集 (Datasets)**、**Notebooks (Kernels)**、**竞赛 (Competitions)**；
- 每条给出 `ref`、标题、规模/下载量/票数、官方链接与「为什么相关」；
- `ref` 可直接喂给 CLI（`kaggle datasets download -d <ref>`、`kaggle kernels pull <ref>`）。

> 检索方式：Kaggle CLI 2.2.4 的 `kaggle datasets|kernels|competitions list -s "<关键词>"`。
> **版本差异提示**：官方 skill 文档描述的 `kaggle search` 统一检索子命令在 2.2.4 中**不存在**（`invalid choice: 'search'`），故改用各分组自带的 `-s/--search`。

## 研究流程（每个策略统一执行）

1. **锁定目标基准**：在策略 README 第一节确认 CAGR / Sharpe / 第三指标 / 容量作为验收阈值。
2. **数据准备**：按 README 第四节接入对应市场历史数据（含手续费与滑点模型）。
3. **回测复现**：在目标时间窗与成本口径下复现目标指标。
4. **稳健性验证**：Walk-Forward（WFE ≥ 60%）+ 蒙特卡洛 10000 次路径 + 噪声 / 滑点敏感性。
5. **结论归档**：达标即判定「研发成功」，回写本清单状态并升级为正式策略目录；未达标则记录缺口并进入下一轮迭代。
