# 待研究与回测策略池 (To-Research Strategy Pool)

本目录存放**尚待研究、复刻与回测验证**的量化策略。所有策略均逆向自公开生态（春江智能 Chunjiang Intelligence 官网 https://www.chunjiang.dev/ 、其 GitHub 组织仓库、Hugging Face 模型，以及录屏 / B 站量化教学素材）。

> **核心约束（重要）**：每个策略目录的 `README.md` 第一节均写明该策略 **官方公布的结果定义**（CAGR / Sharpe / 第三指标 / 简介 / 设计 / 参数 / 容量）。
> **该官方结果即被声明为「策略逆向研发成功」的定义与最终约束**——只有在同口径数据上、计入真实手续费与滑点后复现官方指标（容差内）并通过样本外/滚动验证，方可判定该策略逆向研发成功。
> 对官网未公布结果的策略（010 / 011 / 012），则以录屏实盘证据或可验证的数学命题作为成功定义（详见各自 README）。

## 研究流程（每个策略统一执行）

1. **对齐官方结果定义**：在策略 README 第一节锁定官方 CAGR / Sharpe / 第三指标 / 容量作为验收阈值。
2. **数据准备**：按 README 第四节接入对应市场历史数据（含手续费与滑点模型）。
3. **回测复现**：在相同时间窗与成本口径下复现官方指标。
4. **稳健性验证**：Walk-Forward（WFE ≥ 60%）+ 蒙特卡洛 10000 次路径 + 噪声 / 滑点敏感性。
5. **结论归档**：达标即判定「逆向研发成功」，回写本清单状态并升级为正式策略目录；未达标则记录缺口并进入下一轮迭代。
