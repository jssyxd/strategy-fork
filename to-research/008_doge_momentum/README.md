## 二、策略核心机制与数学原理

1. **微观结构情绪因子**：巨鲸大单净流入 (Whale Inflow)、累计成交量差 (CVD)、活跃地址增量等。
2. **非线性动量模型**：深度学习捕捉情绪驱动的动量爆发节点。
3. **动态止损 / 止盈**：追踪止损 + 分批止盈（保留彩票仓位）。
4. **实盘运行器**：事件驱动扫描 + 风控闸门。
