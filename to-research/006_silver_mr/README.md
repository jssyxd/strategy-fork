## 二、策略核心机制与数学原理

1. **受约束最优控制做市**：保留价格 `r = s − q·γ·σ²·(T−t)`，库存偏多时内部公允价下移、卖单主动靠近。
2. **动态非对称挂单**：半价差随瞬时波动率缩放，库存偏置使买卖挂单非对称，主动去库存。
3. **在线蒸馏 + 数据合成**：以教师模型在线蒸馏克服高频样本稀疏。
4. **容量估计**：L2 盘口离散器 + Q-Learning 冲击乘数 Oracle 估算逆向选择概率。
