## 二、策略核心机制与数学原理

1. **波动率预测网络**：`feature_size=30 / d_model=28 / 3 层`，联合输出波动率、相关性、CVaR，损失 `L = 1.0·L_vol + 0.5·L_corr + 1.0·L_var`。
2. **深度对冲优化器**：以持仓结构 + 期权链计算最优对冲标的与手数，最小化残余 Delta/Gamma 并惩罚交易成本。
3. **期权多腿状态机**：预测概率 ≥0.60 买入跨式；≥0.51 卖出铁鹰；逆转时平仓保护。
4. **筹码引擎**：获利盘比例、加权成本、集中度辅助现货趋势判断。
