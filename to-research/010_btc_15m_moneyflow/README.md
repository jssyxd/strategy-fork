## 二、策略核心机制与数学原理

1. **15m 波段动量跟踪**：双 EMA 动量加速度 + 波动率自适应阈值。
2. **VIX 动态风险滤网**：高波动突变期自动压缩敞口。
3. **基准相对强弱**：与 QQQ / S&P500 动态比对。
4. **资金流突变**：主力净流入、买卖盘失衡度监控。
